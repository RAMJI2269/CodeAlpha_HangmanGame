# CodeAlpha Hangman Game 🎮

## 📌 About the Project
This is a simple console-based Hangman Game developed using Python
as part of my Python Development Internship at CodeAlpha.

In this game, the computer randomly selects a word from a predefined
list of five words. The player must guess the word one letter at a time.

The player can make a maximum of 6 incorrect guesses.

## ✨ Features
- Random word selection
- Letter-by-letter guessing
- Displays correctly guessed letters
- Tracks incorrect guesses
- Prevents repeated guesses
- Input validation
- Win and lose conditions

## 🛠️ Technologies Used
- Python
- Random module

## 🎯 How to Play
1. Run the program.
2. Guess one letter at a time.
3. Correct guesses reveal the letters in the word.
4. Incorrect guesses increase the error count.
5. Guess the complete word before reaching 6 incorrect guesses to win.
